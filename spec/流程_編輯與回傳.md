# 流程_編輯與回傳

## 觸發

使用者在編輯區輸入、貼上、套用工具列格式、復原或重做時，編輯器把變更後的整份 markdown 內容回傳給頁面；頁面可把收到的內容寫回編輯器（雙向綁定）、延後寫回、修整後寫回、不寫回，或轉交其他編輯器顯示。本文件涵蓋各種編輯方式與頁面回寫方式之組合下，編輯過程不重載、內容完整、游標維持在輸入位置。

- 入口：示範宿主頁（`spec/設計要點與取捨.md` 第二節）。
- 版面：同 `流程_編輯器載入與關閉`；本流程另用「備忘」輸入欄作為複製來源、工具列「粗體 <Ctrl+B>」「復原 <Ctrl+Z>」。
- 預設狀態：可編輯、文件 `ORI`、頁面同步回寫，編輯器回傳之防抖 100 毫秒。

## 重要流程

- **E2E-001**
  - title: 逐字輸入時頁面同步回寫
  - description: 在編輯區文件末尾逐字輸入時，編輯器在停止輸入片刻後就把整份內容回傳給頁面，頁面以雙向綁定立即寫回；輸入過程中已輸入的文字不會消失、開頭不會被插入其他內容，接著輸入的字也接在末尾，按一次工具列的「復原 <Ctrl+Z>」只撤銷最後一次輸入。回傳只交給頁面，是否存回伺服器由頁面決定。適合一般表單以雙向綁定使用編輯器。
  - flow:
    - 測試資料：預設文件 `ORI`，頁面同步回寫（`writeMode=sync`）。
    - 操作：開啟示範宿主頁 → 等載入完成 → 點擊編輯區、按 Ctrl+End → 以每鍵 150 毫秒輸入 abcd → 等頁面收到結尾為 abcd 之回傳 → 輸入 Y → 等頁面收到結尾為 abcdY 之回傳 → 停頓 0.6 秒 → 點擊「復原 <Ctrl+Z>」一次。頁面會回寫者，每次輸入後另等頁面持有之內容與最後回傳一致。
    - 驗證：
      1. 語意：①輸入過程每 20 毫秒取樣之編輯區文字皆以開啟時內容開頭、其後為 abcd 之前綴且長度不減少；②輸入後編輯區為開啟時內容接 abcd；③頁面持有之內容與最後回傳一致（忽略結尾空白）；④Y 接於 abcd 之後；⑤復原一次後回到開啟時內容接 abcd；⑥主控台無錯誤。
      2. 視覺：無。
    - 模式：三模式各一輪。
    - 清理：不變動資料；瀏覽器每案全新。
    - 備註：每鍵 150 毫秒慢於回傳防抖 100 毫秒，使每鍵各自回傳並被頁面寫回，寫回之值等於最後回傳值，不重載（`isEcho`）。原測試：R12 同步回寫（三模式）。

- **E2E-002**
  - title: 頁面延後一拍回寫時輸入不受影響
  - description: 頁面收到回傳後若在下一個處理時點才寫回，例如經過狀態管理再更新，逐字輸入同樣不會重載、已輸入的文字不會消失，接著輸入的字接在末尾，按一次「復原 <Ctrl+Z>」只撤銷最後一次輸入。適合經狀態管理或非同步流程更新內容的頁面。
  - flow:
    - 測試資料：預設文件 `ORI`，頁面於下一個微任務寫回（`writeMode=micro`）。
    - 操作：同 E2E-001。
    - 驗證：
      1. 語意：同 E2E-001 之①～⑥。
      2. 視覺：無。
    - 模式：三模式各一輪。
    - 清理：不變動資料；瀏覽器每案全新。
    - 備註：原測試：R12 微任務回寫（三模式）。

- **E2E-003**
  - title: 頁面於停止輸入後才回寫時輸入不受影響
  - description: 頁面在使用者停止輸入一段時間後才寫回最後收到的內容時，逐字輸入期間編輯區不會被舊內容蓋掉，停止後頁面持有的內容與編輯區一致，接著輸入的字接在末尾，按一次「復原 <Ctrl+Z>」只撤銷最後一次輸入。適合為減少更新次數而延後同步的頁面。
  - flow:
    - 測試資料：預設文件 `ORI`，頁面於停止收到回傳 300 毫秒後寫回最後一筆（`writeMode=debounce300`）。
    - 操作：同 E2E-001；每次輸入後另等頁面持有之內容與最後回傳一致。
    - 驗證：
      1. 語意：同 E2E-001 之①～⑥。
      2. 視覺：無。
    - 模式：三模式各一輪。
    - 清理：不變動資料；瀏覽器每案全新。
    - 備註：頁面只寫回最後一筆，等於最後回傳值，不重載。原測試：R12 debounce300 回寫（三模式）。

- **E2E-004**
  - title: 頁面修整結尾空白後回寫時輸入不受影響
  - description: 頁面把收到的內容去除前後空白後才寫回時，結尾換行的差異不會讓編輯器重載，逐字輸入不會中斷，接著輸入的字接在末尾，按一次「復原 <Ctrl+Z>」只撤銷最後一次輸入。適合儲存前會修整空白的頁面。
  - flow:
    - 測試資料：預設文件 `ORI`，頁面修整兩端空白後寫回（`writeMode=trim`）。
    - 操作：同 E2E-001。
    - 驗證：
      1. 語意：同 E2E-001 之①～⑥（③以去除結尾空白後比對）。
      2. 視覺：無。
    - 模式：三模式各一輪。
    - 清理：不變動資料；瀏覽器每案全新。
    - 備註：回寫判斷忽略結尾空白與換行符差異（`normEcho`）；開頭空白之修整見 `流程_頁面更新內容` 之分割預覽案例。原測試：R12 trim 回寫（三模式）。

- **E2E-005**
  - title: 頁面不回寫時輸入照常且頁面內容不變
  - description: 頁面只接收回傳而不寫回編輯器時，使用者照常逐字輸入，內容不會重載或消失，接著輸入的字接在末尾，按一次「復原 <Ctrl+Z>」只撤銷最後一次輸入；頁面持有的內容維持原本的值，直到頁面自行更新。適合只在送出時才讀取編輯內容的頁面。
  - flow:
    - 測試資料：預設文件 `ORI`，頁面不回寫（`writeMode=none`）。
    - 操作：同 E2E-001。
    - 驗證：
      1. 語意：同 E2E-001 之①②④⑤⑥；③改為頁面持有之內容仍為 `ORI` 原文。
      2. 視覺：無。
    - 模式：三模式各一輪。
    - 清理：不變動資料；瀏覽器每案全新。
    - 備註：之後頁面改值仍會載入，見 `流程_頁面更新內容` 之不回寫案例。原測試：R12 不回寫（三模式）。

- **E2E-006**
  - title: 頁面自備語系資料時逐字輸入正常
  - description: 頁面自備語系資料並以雙向綁定使用編輯器時，逐字輸入同樣不會重載，接著輸入的字接在末尾，按一次「復原 <Ctrl+Z>」只撤銷最後一次輸入。適合內網部署的頁面。
  - flow:
    - 測試資料：預設文件 `ORI`，頁面自備語系資料（`i18n=1`），同步回寫。
    - 操作：同 E2E-001。
    - 驗證：
      1. 語意：同 E2E-001 之①～⑥。
      2. 視覺：無。
    - 模式：只測所見即所得；理由：語系之取得方式只影響載入時序，與輸入及模式無關。
    - 清理：不變動資料；瀏覽器每案全新。
    - 備註：原測試：R12 settings.i18n 同步回寫。

- **E2E-007**
  - title: 中文輸入法組字完整接於末尾
  - description: 以注音等中文輸入法在文件末尾組字時，組字期間的注音不會被當成內容回傳，選字後的文字完整接在末尾，開頭不會被插入其他內容，頁面持有的內容與最後回傳一致。適合以中文輸入法編輯的使用者。
  - flow:
    - 測試資料：預設文件 `ORI`，頁面同步回寫。
    - 操作：開啟示範宿主頁 → 等載入完成 → 點擊編輯區、按 Ctrl+End → 以輸入法依序組字「ㄓㄨㄥ」選「中」、「ㄨㄣˊ」選「文」、「ㄗˋ」選「字」，每字選定後停 350 毫秒 → 等頁面收到結尾為中文字之回傳。
    - 驗證：
      1. 語意：①編輯區為開啟時內容接「中文字」；②編輯區開頭未被插入；③頁面持有之內容與最後回傳一致；④主控台無錯誤。
      2. 視覺：無。
    - 模式：三模式各一輪。
    - 清理：不變動資料；瀏覽器每案全新。
    - 備註：組字以瀏覽器輸入管線之輸入法指令送出（CDP `Input.imeSetComposition`、`Input.insertText`），Playwright 無組字 API，屬 L1.5 輸入法注入（`CLAUDE_rulebook.md` 映射〈偏離與依據〉）。每字停 350 毫秒逾回傳防抖，每字皆回傳並寫回。原測試：R12 中文輸入法組字（三模式）。

- **E2E-008**
  - title: 回傳內容同步顯示於另一個編輯器
  - description: 頁面把一個編輯器回傳的內容同時交給另一個編輯器顯示時，在第一個編輯器逐字輸入，另一個編輯器隨之顯示相同內容，而第一個編輯器不會因此重載或遺失輸入。兩個編輯器只同步顯示，不是多人共同編輯；多人同時編輯需頁面另行支援協作機制。適合編輯區與預覽區並列，或主從顯示同一份內容的頁面。
  - flow:
    - 測試資料：預設文件 `ORI`，另一個編輯器綁定同一份頁面內容（`shared=1`），同步回寫。
    - 操作：開啟示範宿主頁 → 等兩個編輯器載入完成 → 於第一個編輯器點擊編輯區、按 Ctrl+End → 以每鍵 150 毫秒輸入 abcd → 等頁面收到結尾為 abcd 之回傳 → 等另一個編輯器顯示相同內容。
    - 驗證：
      1. 語意：①第一個編輯器輸入過程取樣無重載（同 E2E-001 之①）；②第一個編輯器為開啟時內容接 abcd；③另一個編輯器之文字與第一個相同；④頁面持有之內容與最後回傳一致；⑤主控台無錯誤。
      2. 視覺：無。
    - 模式：三模式各一輪。
    - 清理：不變動資料；瀏覽器每案全新。
    - 備註：共編之協調屬頁面（`spec/設計要點與取捨.md` 裁決紀錄）。原測試：R12 父層把回拋值單向同步至另一組件（三模式）。

- **E2E-009**
  - title: 貼上後立即回傳且接著輸入接於末尾
  - description: 在頁面其他欄位複製文字，例如「備忘」欄的文字，再到編輯區文件末尾按 Ctrl+V 貼上，貼上的內容出現在游標處，編輯器隨即把變更回傳給頁面，接著輸入的字接在貼上內容之後，開頭不會被改動。貼上只回傳給頁面，是否存回伺服器由頁面決定。適合從其他欄位或文件搬移內容。
  - flow:
    - 測試資料：預設文件 `ORI`，「備忘」欄文字 PASTE，頁面同步回寫。
    - 操作：開啟示範宿主頁 → 等載入完成 → 點擊「備忘」欄 → 按 Ctrl+A、Ctrl+C → 點擊編輯區、按 Ctrl+End → 按 Ctrl+V → 等頁面收到含 PASTE 之回傳 → 輸入 Y → 等頁面收到結尾為 Y 之回傳。
    - 驗證：
      1. 語意：①編輯區以開啟時內容開頭；②開頭以後之文字去除空白為「PASTEY」；③頁面至少收到 2 次回傳；④頁面持有之內容與最後回傳一致；⑤主控台無錯誤。
      2. 視覺：無。
    - 模式：三模式各一輪。
    - 清理：剪貼簿隨瀏覽器關閉消失；瀏覽器每案全新。
    - 備註：分割預覽於 Ctrl+End 後游標在結尾換行之後，貼上內容落在新的一行（`spec/evidence/2026-10-04-host-probe1.log` 之 P3）。原測試：R16 貼上（三模式；原以程式寫入剪貼簿，今改為由頁面欄位複製）。

- **E2E-010**
  - title: 選取文字後點擊「粗體」立即回傳
  - description: 在編輯區選取剛輸入的文字後，點擊工具列的「粗體 <Ctrl+B>」按鈕，文字套用粗體，編輯器隨即把變更回傳給頁面，開頭內容不受影響；按 End 鍵後接著輸入的字接在末尾。格式變更只回傳給頁面，是否存回伺服器由頁面決定。適合以工具列調整文字格式。
  - flow:
    - 測試資料：預設文件 `ORI`，頁面同步回寫。
    - 操作：開啟示範宿主頁 → 等載入完成 → 點擊編輯區、按 Ctrl+End → 以每鍵 150 毫秒輸入 abc → 等頁面收到結尾為 abc 之回傳 → 按住 Shift 按 3 次左方向鍵 → 點擊「粗體 <Ctrl+B>」 → 等頁面收到含 `**abc**` 之回傳 → 按 End → 輸入 Y → 等編輯區以 Y 結尾且頁面收到新的回傳。
    - 驗證：
      1. 語意：①套用後編輯區以開啟時內容開頭；②點擊後頁面收到新的回傳；③頁面持有之內容含 `**abc**`；④頁面持有之內容與最後回傳一致；⑤輸入 Y 後編輯區以開啟時內容開頭且去除空白後以 Y 結尾；⑥主控台無錯誤。
      2. 視覺：無。
    - 模式：三模式各一輪。
    - 清理：不變動資料；瀏覽器每案全新。
    - 備註：所見即所得於套用粗體後按 End，游標仍在粗體內，Y 併入粗體，回傳結尾為粗體標記而非 Y，故以編輯區之可見文字判定。原測試：R16 工具列（三模式）。

- **E2E-011**
  - title: 鍵盤復原與重做立即回傳
  - description: 輸入文字後在編輯區按 Ctrl+Z 撤銷最後一次輸入、再按 Ctrl+Y 重做，每次都立即把變更回傳給頁面，頁面持有的內容與編輯區一致；之後接著輸入的字接在末尾。復原與重做只回傳給頁面，是否存回伺服器由頁面決定。適合以鍵盤快速修正輸入。
  - flow:
    - 測試資料：預設文件 `ORI`，頁面同步回寫。
    - 操作：開啟示範宿主頁 → 等載入完成 → 點擊編輯區、按 Ctrl+End → 以每鍵 150 毫秒輸入 abc → 等頁面收到結尾為 abc 之回傳 → 停頓 0.6 秒 → 按 Ctrl+Z → 等編輯區為開啟時內容接 ab → 按 Ctrl+Y → 等編輯區為開啟時內容接 abc → 輸入 Y → 等頁面收到結尾為 abcY 之回傳。
    - 驗證：
      1. 語意：①復原後編輯區為開啟時內容接 ab，頁面持有之內容與最後回傳一致；②重做後為開啟時內容接 abc，頁面持有之內容與最後回傳一致；③Y 接於 abc 之後；④主控台無錯誤。
      2. 視覺：無。
    - 模式：三模式各一輪。
    - 清理：不變動資料；瀏覽器每案全新。
    - 備註：每鍵 150 毫秒使每個字為一個復原步驟。原測試：R16 鍵盤復原與重做（三模式）。

- **E2E-012**
  - title: 全選刪除後重新輸入只留新內容
  - description: 在編輯區按 Ctrl+A 全選後按 Backspace 刪除全部內容，再輸入新文字，編輯區只剩新輸入的文字，舊內容不會因重載而重新出現，頁面持有的內容也只有新文字。此操作會取代整份內容並回傳給頁面，是否存回伺服器由頁面決定。適合整份重寫文件。
  - flow:
    - 測試資料：預設文件 `ORI`，頁面同步回寫。
    - 操作：開啟示範宿主頁 → 等載入完成 → 點擊編輯區 → 按 Ctrl+A → 按 Backspace → 以每鍵 150 毫秒輸入 NEW → 等頁面收到結尾為 NEW 之回傳。
    - 驗證：
      1. 語意：①編輯區文字為「NEW」；②頁面持有之內容去除結尾空白為「NEW」；③主控台無錯誤。
      2. 視覺：無。
    - 模式：三模式各一輪。
    - 清理：不變動資料；瀏覽器每案全新。
    - 備註：原測試：R16 全選刪除後輸入（三模式）。

## 測試資料

| 變體 | 具名對象 | 取用方式 | 選它的理由 |
|---|---|---|---|
| 頁面回寫方式 | `sync`、`micro`、`debounce300`、`trim`、`none` | `writeMode` | 涵蓋同步、延後一拍、延後至停止、修整、不回寫五類常見整合方式 |
| 編輯方式 | 逐字輸入、輸入法組字、貼上、工具列粗體、鍵盤復原重做、全選刪除 | 各案例操作 | 涵蓋 vditor 觸發回傳之各入口（鍵盤、輸入法、剪貼簿、工具列、復原紀錄） |
| 複製來源 | 「備忘」欄文字 PASTE | `docs.json` 之 `NOTE` | 純文字，貼上後易於比對 |
