# 2026-10-04 vditor 4.0.0 是否已改上游事項之寫法

查核方式：`npm pack vditor@4.0.0`（npm 最新版，發布於 2026-08-30；本專案安裝 3.11.3，發布於 2026-08-11）解開後比對原始碼。

| 上游事項 | vditor 4.0.0 之位置 | 結果 |
|---|---|---|
| 載入排版引擎之 `.then` 不檢查 `isDestroyed`、無 `catch` | `src/index.ts` 519–595（`init`；入口 520 行檢查，552 行 `addScript(...).then` 內不檢查） | 未變 |
| `destroy` 呼叫 `UIUnbindListener`、移除共用之 `vditorIconScript` | `src/index.ts` 404–413 | 未變 |
| 視窗縮放監聽存於模組層單一變數 | `src/ts/ui/initUI.ts` 158–167（`resizeCb`、`UIUnbindListener`） | 未變 |
| iPhone 之 `visualViewport` 監聽不移除 | `src/ts/ui/initUI.ts` 103–104 | 未變 |
| 所見即所得編輯區建構式先綁定捲動監聽再讀 `comment.enable` | `src/ts/wysiwyg/index.ts` 62、73 | 未變 |
| 語系失敗之提示條附加於 body、`hide` 只清內容 | `src/index.ts` 101（`showErrorTip`）；`src/ts/tip/index.ts` 與 3.11.3 逐字相同 | 未變 |

| `initUI.ts` 與 3.11.3 之差異 | 只有 `setTypewriterPosition` 改為分割預覽模式另設 `paddingBottom`（149–155 行） | 與上列事項無關 |

結論：升級至 vditor 4.0.0 不會改變 `spec/設計要點與取捨.md` 第六節所列之上游事項。另見 `2026-10-04-destroy-probe7.log`：就緒後每關閉再開啟一次，body 多一份圖示 SVG（`dist/js/icons/ant.js` 約 43KB、53 個圖示）。
