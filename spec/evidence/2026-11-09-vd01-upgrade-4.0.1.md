## 3. 分割預覽取消選取之通知探測

探測（暫存測試，不入庫；`quiet-run --lock` 執行）：分割預覽、文件 `LONG`、`cbLog=1`，以滑鼠拖曳選取，再點擊編輯區右上角空白處，再按右方向鍵：

```
{"editable":"1","afterSelect":["select"],"afterClick":["select"],"afterArrow":["select","keydown"]}
{"editable":"0","afterSelect":["select"],"afterClick":["select"],"afterArrow":["select"]}
```

可編輯與唯讀皆不呼叫 `unSelect`（vditor 4 之分割預覽只監聽 textarea 之 `select` 事件，`ts/sv/index.ts:73-82`；取消選取不觸發該事件）。依封裝權責不由組件補發，記入 `流程_唯讀時之焦點`〈已知落差〉。

## 5. 焦點保留探測

唯讀（`editable=0`）、文件 `LONG`、`focusLog=1`、9 秒後頁面載入 `NEW_SHORT`；先以 Tab 鍵取得編輯區本身之焦點，資料送達後再等 1.5 秒：

```
{"mode":"wysiwyg","focusedBefore":true,"focusedAfter":false,"fl":["focus","blur"]}
{"mode":"ir","focusedBefore":true,"focusedAfter":false,"fl":["focus","blur"]}
{"mode":"sv","focusedBefore":true,"focusedAfter":true,"fl":["focus"]}
```

所見即所得與即時渲染於載入新內容時重建編輯區，焦點丟失（組件 JSDoc `value` 已載明「載入時若編輯區持有焦點，游標不保留」）；分割預覽保留焦點且無多餘之聚焦／失焦通知，故 `lockSvEditor` 於工具列被重新啟用而再度呼叫 `disabled()` 時之屬性切換不丟失焦點。

## 6. 預覽 XSS（GHSA-x2mx-f527-mxr9）

- 探測：`spec/evidence/2026-11-09-vd01-xss-probe.json`（以 `Vditor.preview` 渲染，3.11.3 與 4.0.1 並排，外部請求一律阻擋）：
  - `<a href='x" onerror="window.__xss=1" a=".mp4'>v</a>`：3.11.3 產生 `<video controls="controls" src="x" onerror="window.__xss=1" a=".mp4">`，`window.__xss` 為 1；4.0.1 產生 `src="x&quot; onerror=&quot;window.__xss=1&quot; a=&quot;.mp4"`，旗標未設。`.mp3` 之音訊分支同。
  - Markdown 寫法 `[v](x"onerror="window.__xss=1"a.mp4)` 於兩版皆被淨化為 `x%22onerror=%22…`，不構成夾帶。
  - 正常連結 `[v](/media/a.mp4)` 兩版皆為 `<video controls="controls" src="/media/a.mp4">`。
- 組件層（細節見本節末與第 7 節）：`test/e2e-preview.test.mjs`（`流程_預覽之媒體連結安全`）4 案於 4.0.1 全綠；以 3.11.3 之變異副本（`E2E_SRC_DIR=tmp/vd01/mut-old-vditor`、`E2E_VDITOR_DIR=tmp/vd01/old/package`）跑，E2E-001、002、004 紅（斷言訊息 `"xss":1` 與播放器屬性含 `onerror`），E2E-003 綠（正常連結之對稱案例）。

## 7. 拖放探測（唯讀與可編輯，以真滑鼠自頁面選取之文字拖至編輯區）

文件 `ORI`，雙擊 `#mdout` 首行選取「標題」，按住拖曳至編輯區後放開，等 1.2 秒：

```
wysiwyg editable=1: changed=true,  inputs=1  after="標題標題 第一段內容abc 第二段內容xyz"
wysiwyg editable=0: changed=false, inputs=0
ir      editable=1: changed=false, inputs=1  （有回傳，編輯區可見文字未變）
ir      editable=0: changed=false, inputs=0
sv      editable=1: changed=true,  inputs=1  after="# 標題 … ``` 標題 ```"（被插入為程式碼區塊）
sv      editable=0: changed=false, inputs=0
```

唯讀時三模式皆不變；移除組件之 `drop` 攔截（M6）後唯讀仍不變，故唯讀之編輯區不接受拖放，`流程_唯讀鎖定` E2E-014 守護此可觀察不變式。
